\## 📌 About



This project analyzes student performance using Python and Pandas.



The main goal is to understand how different factors such as study time, absences, tutoring, and parental support are related to students' GPA.



\---



\## 📂 Dataset



\*\*Dataset:\*\* Student Performance Dataset



\*\*Source:\*\* Kaggle



The dataset contains information about students, including:



\- Age

\- Gender

\- Study Time

\- Absences

\- Tutoring

\- Parental Support

\- GPA

\- Grade Class

\## 🔍 Analysis



The following analysis was performed:



\- 📚 Study Time vs GPA

\- 📅 Absences vs GPA

\- 👨‍👩‍👧 Parental Support vs GPA

\- 👨‍🏫 Tutoring vs GPA

\- 🎓 Overall Student Performance



\---



\## 📈 Key Findings



\- Students with higher study time tend to have higher GPA.

\- Higher absences are associated with lower GPA.

\- Parental support shows a positive relationship with GPA.

\- Tutoring students have a slightly higher average GPA.
